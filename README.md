Bienvenue sur le dépôt du groupe **CARTEL**. Ce projet regroupe deux composants principaux développés dans le cadre de notre formation : un outil de scraping web et un algorithme de gestion commerciale.

## À propos

Ce dépôt contient le travail réalisé par le groupe CARTEL dans le cadre d'un projet académique comprenant deux volets distincts :

1. **Web Scraping** : Extraction automatisée de données depuis un site web
2. **Gestion Commerciale** : Implémentation d'un algorithme de gestion commerciale

##  Structure du projet

```
CARTEL/
├── README.md
├── scraper.py
└── algo.py
```

##  Fichiers

### `scraper.py`

Script de web scraping développé pour extraire diverses données d'un site web fourni par le professeur.

**Fonctionnalités :**
-  Extraction des images
-  Récupération des titres
-  Extraction des paragraphes
-  Collecte des liens
-  Récupération du formulaire

**Technologies utilisées :**
- Python
- BeautifulSoup4 
- Requests

### `algo.py`

Algorithme de gestion commerciale implémentant la logique complète d'une application de gestion d'entreprise.

**Concepts couverts :**
- Gestion des stocks
- Suivi des ventes
- Gestion des clients
- Calculs financiers
- Génération de rapports
- Vérification de la cohérence des données

**Fonctionnalités principales :**
- Ajout de produit
- Afficher les stocks
- Mettre a jour une quantité
- Rechercher un produit
- Supprimer un produit
- Acheter un produit

##  Installation

### Prérequis

- Python 3.7 ou supérieur
- pip (gestionnaire de paquets Python)

### Étapes d'installation

1. Clonez le dépôt :
```bash
git clone https://github.com/votre-repo/CARTEL.git
cd CARTEL
```

2. Installez les dépendances nécessaires :

pip install requests beautifulsoup4 
```

##  Utilisation

### Utilisation du scraper

```bash
python scraper.py
```

Le script va extraire les données du site web configuré et les sauvegarder dans des fichiers appropriés.

### Utilisation de l'algorithme de gestion

```bash
python algo.py
```

L'algorithme exécutera les opérations de gestion commerciale selon la logique implémentée.
